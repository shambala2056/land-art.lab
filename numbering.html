Tree numbering plan

Every certificate carries a code that says which hexagon the trees are in and which certificate it is within that hexagon. This is the whole scheme: the letter each cell carries, where it sits on the ground, and the codes it will issue.

AB-007
the hexagon
the seventh certificate in it
  • One letter per hexagon. A to Z, then AA to BB — fifty-four in all, one for every cell on the site.
  • Letters run across the ground, north-west to south-east, so neighbouring cells carry neighbouring letters and a cell can be found by walking to it.
  • Three digits, counted within that cell. The largest cell holds 863 pits, so three is enough for good.
  • No code can ever repeat. Each cell counts on its own, and the letter in front keeps two cells apart however their counts run. Within a cell the number comes from a single atomic step, so two payments landing in the same instant take different numbers.
  • Numbers are issued when a payment clears, never when an order is started — an abandoned checkout must not leave a hole in a cell's sequence.
  • One pit is three saplings and one certificate.
