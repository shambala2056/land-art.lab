# Гэрчилгээний эх

`certificate.png` — 2670 × 3698, босоо. Танай өгсөн `Hexagon certificate.png`.
Нэр, дугаар хоёрыг энэ зураг дээр `certificate.html` буулгана.

## Хэмжсэн байрлал

`layout.json` доторх тоо энэ зурганаас хэмжигдсэн:

| | |
|---|---|
| `THIS CERTIFICATE IS PROUDLY PRESENTED TO` | x = 251, суурь шугам y = 1763 |
| `TREE NUMBER:` доорх зураас | y = 3047, x 254 → 2494 |
| **Нэр** | x = 251, суурь y = 2150, зүүн тэгшилсэн, **230px**, хамгийн ихдээ **2 мөр** |
| **Дугаар** | x = 254, суурь y = 3320, **зураасны доор**, **248px** |

## Фонт

| Талбар | Фонт |
|---|---|
| Нэр | **Abril Fatface Regular** |
| Модны дугаар | **Montserrat Bold** |

Хоёулаа Google Fonts-оос ачаалагдана (`certificate.html`-ийн `<head>`). Кирилл
дэмжинэ — шалгасан.

**Нэрний хэмжээ уртаасаа хамаарна.** Богино нэр 230px-ээр нэг мөрөнд. Багтахгүй
бол хоёр мөр болно — жижигрэхгүй, учир нь нэг мөрөнд шахаад жижгэрүүлбэл
дээрх шошгоноосоо жижиг болж, алдаа мэт харагдана. Хоёр мөрөнд ч багтахгүй
байж байж хэмжээ нь буурна. Хоёр мөр нь суурь шугамын хоёр тал руу тэнцүү
тавигдах тул блок нь эхийн үлдээсэн зайд (y 1800–2470) хэвээр байна.

Мөрийн тоог `maxLines`, мөр хоорондын зайг `lineHeight` тохируулна.

## Эх солих бол

1. Шинэ файлаа энэ хавтсанд тавь.
2. `layout.json` доторх `sheet.width`, `sheet.height`, `name`, `number`-ийн
   тоог л сольж таарууул. **Кодод гар хүрэх шаардлагагүй.**
3. Урьдчилан хараад шалга:

```
http://localhost:8787/certificate.html?preview=1&name=ОЮУНДАРЬ%20БАТСҮХ&n=42
http://localhost:8787/certificate.html?preview=1&kind=story&name=ОЮУНДАРЬ%20БАТСҮХ&n=42
```

Урт нэр өгч заавал үзээрэй.

## Стори (1080 × 1920)

Тусдаа стори эх ирээгүй тул одоогоор **гэрчилгээг өөрийг нь** 9:16 суурин
дээр тавьж байна. Дэвсгэр нь гэрчилгээний толгойн цайвар өнгө (`#FFFAF1`) —
ногооноор тавихад гэрчилгээний ногоон хагасын ирмэг алга болж байсан.

Зориулж зохиомжилсон стори хүсвэл **1080 × 1920** файл өгөөд `layout.json`-ы
`story` дотор `"art": "assets/tree-certificate/story.png"` гэж нэм. Дээд ба
доод 250 px-т унших ёстой зүйл бүү тавь — Instagram тэнд өөрийн товчоо тавина.

## Модны дугаарлалт

Худалдан авалт нь hexagon-ы нүд дээр дарж хийгддэг тул **гэрчилгээний дугаар нь
тухайн нүдний кодоор** дугаарлагдана:

```
D-06-0007
└──┘ └──┘
 нүд   тухайн нүд доторх дараалал
```

**Давхцах боломжгүй.** Хоёр зүйл үүнийг баталгаажуулдаг, хоёул хэрэгтэй:

1. Нүд бүр өөрийн тоолууртай (`trees:{cell}`), код нь нүдний кодоор эхэлдэг.
   Тоолуурууд нь хэрхэн ч явсан хоёр өөр нүд ижил код гаргаж чадахгүй.
2. Нүд дотор `INCRBY` нь **нэг атомын үйлдэл** — нэмсний ДАРААХ утгыг буцаана.
   Эхэлж ирсэн нь тэр блокийг авна, яг тэр агшинд ирсэн нь дараагийнхыг авна.
   Уншаад-дараа-нь-бичих арга бол хоёуланд нь ижил дугаар өгөх алдаа мөн.

Нэг нүдэнд 12 төлбөрийг зэрэг тооцуулж шалгасан: 12 код, 12 өөр утга.

Дугаарыг **төлбөр батлагдсаны дараа** олгоно — орхигдсон сагс дугаар шатааж,
нүдний дараалалд нүх үлдээх ёсгүй. Мөн нэг захиалгад хоёр удаа олгогдохгүй:
төлбөр callback болон хөтчийн буцалт гэсэн хоёр замаар бүртгэгддэг ч аль
хэдийн блоктой захиалга түүнийгээ хадгална.

**1 нүх = 3 мод = 1 гэрчилгээ.** 2 нүх авбал `D-06-0001` ба `D-06-0002`.

Хэлбэрийг `layout.json`-ы `numberFormat` (`{prefix}-{n}`) ба `numberPad`
(4 орон) тодорхойлно.
